# 视觉素材制作清单

本作品全部视觉素材由"AI 生成 + Photoshop 人工修正"制作，统一青蓝科普风。

## 素材清单

| # | 素材文件 | 用途 | 说明 |
| ---- | ---- | ---- | ---- |
| 1 | images/hero.png | 首页主视觉 | 石油化工-加油站-汽车场景插画，AI 生成后 PS 统一色调 |
| 2 | images/flow.png | 全生命周期旅程图 | 五阶段流程插画，PS 修正管线/油罐结构 |
| 3 | images/exploration.png | 开采环节图 | 钻井平台场景，AI 生成 + 结构修正 |
| 4 | images/refining.png | 炼化环节图 | 常减压蒸馏装置图，重点修正塔器结构错误 |
| 5 | images/distribution.png | 配送环节图 | 油罐车配送场景 |
| 6 | images/combustion.png | 燃烧环节图 | 机动车尾气场景 |
| 7 | images/ccus.png | CCUS 技术图 | 碳捕集与地下封存示意，PS 修正注入井结构 |

## 制作规范
- 统一色彩：青蓝（#0e7c86 / #17a2b8 / #4db6ac）。
- AI 生成图均经石油化工专业成员核对工艺结构（塔器、管线、阀门位置）。
- 存在明显工艺错误的图已由 Photoshop 二次修改或弃用重新生成。
- 图表（环形图、柱状图、折线图、雷达图）由 ECharts 基于核实数据实时渲染，非静态图。
