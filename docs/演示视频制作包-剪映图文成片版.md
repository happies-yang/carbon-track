# 演示视频制作包（剪映图文成片版）

本作品演示视频使用剪映制作完成，以下为制作方式说明（用于备赛复现与答辩说明）。

## 素材清单
| 素材 | 用途 | 来源 |
| ---- | ---- | ---- |
| 网页录屏（3 段） | 系统功能演示 | 本地屏幕录制 |
| 片头/尾素材 | 开闭幕画面 | 剪映图文成片 + 自绘 |
| AI 配音 | 旁白解说 | 剪映 AI 配音 |
| 配乐 | 背景音乐 | 剪映音乐库（已核对版权合规） |

## 制作流程
1. **图文成片**：输入讲解文案，剪映自动生成画面底稿。
2. **替换画面**：将 AI 生成的不相关内容替换为网页实机录屏与自绘素材。
3. **插入实机演示**：AI 问答环节保留真实录屏，展示真实 API 调用。
4. **配音与字幕**：AI 配音 + 自动字幕，人工校对专业术语（如"常减压蒸馏""CCUS"）。
5. **节奏剪辑**：总时长控制 3:38，重点环节（AI 实测）节奏放慢。

## 注意事项
- 视频中展示的数据与线上系统一致（2.68 kgCO₂e/L、82.5% 等）。
- 视频末尾列出团队成员与指导教师。
