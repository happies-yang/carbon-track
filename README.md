# 碳迹·油链

**一滴汽油的全生命周期碳足迹智能可视化系统**

第十四届全国大学生数字媒体科技作品及创意竞赛参赛作品 · 指定命题【科技+创意，讲好中国故事】

## 项目简介

在"双碳"目标背景下，本作品以生命周期评价（LCA）为框架，将一滴汽油全生命周期划分为**原油勘探与开采 → 原油运输 → 炼油炼化 → 成品油配送储运 → 机动车终端燃烧**五大环节，通过可交互的网页可视化系统呈现各环节碳排放数据与占比，并集成真实可用的 AI 碳足迹智能问答助手，面向石油化工专业学生与社会大众开展科普传播。

## 核心功能

- 📊 **五阶段碳足迹可视化**：环形图、柱状图、全链条分布
- 🔗 **数据来源可追溯**：每个环节数据均标注标准/文献来源
- 🚗 **燃油车 vs 电动车对比**：每公里碳排放科普对比
- 🤖 **AI 碳足迹助手**：环节解读、数据问答、减排建议（真实调用大模型 API）

## 技术栈

- 原生 HTML + CSS + JavaScript（单页应用）
- ECharts 5 图表库
- 阿里云百炼（通义千问）大模型 API

## 本地运行

直接双击 `index.html` 即可在浏览器打开（需联网加载 ECharts CDN）。

> 线上演示版 AI 功能配置说明：见 `js/ai.js` 顶部注释。
> 系统数据为科普参考值，不作为商业碳足迹认证依据。
